# Duart Panel — Internacionalização (i18n)

## 1. Estratégia de i18n

### 1.1 Princípios

- **Um arquivo por página**: Cada página tem seu próprio arquivo de tradução, evitando arquivos monolíticos
- **Idiomas suportados**: Português (padrão, `pt-BR`), Inglês (`en-US`), Espanhol (`es-ES`)
- **Traduções server-side e client-side**: Arquivos `.js` (CommonJS) carregáveis tanto pelo servidor quanto pelo frontend
- **Fallback chain**: Idioma solicitado → idioma padrão (`pt-BR`) → chave original

### 1.2 Estrutura de Diretórios


## 3. Mecanismo de Carregamento

### 3.1 I18nContext (React)

```typescript
// lib/contexts/I18nContext.tsx (conceitual)

interface I18nContextValue {
  t: (key: string, params?: Record<string, string | number>) => string;
  locale: string;
  setLocale: (locale: string) => void;
  availableLocales: { code: string; name: string; flag: string }[];
}

// Uso no componente:
// const { t } = useI18n();
// <h1>{t('dashboard.title')}</h1>
// <p>{t('common.confirmAction')}</p>
// <p>{t('nginx.siteCreated', { domain: 'meusite.com' })}</p>
```

### 3.2 Resolução de Chaves

A função `t()` resolve chaves no formato `namespace.key` ou `page.section.key`:

```typescript
function resolveTranslation(key: string, locale: string): string {
  // 1. Parse: "dashboard.cpu" → namespace="dashboard", path=["cpu"]
  const [namespace, ...path] = key.split('.');
  
  // 2. Carrega o arquivo correspondente (com cache)
  const translations = loadTranslations(namespace, locale);
  
  // 3. Navega no objeto
  let value = translations;
  for (const part of [namespace, ...path]) {
    value = value?.[part];
  }
  
  // 4. Fallback para pt-BR se não encontrado
  if (value === undefined && locale !== 'pt-BR') {
    return resolveTranslation(key, 'pt-BR');
  }
  
  // 5. Fallback para a chave original
  return value ?? key;
}
```

### 3.3 Interpolação de Parâmetros

```typescript
// languages/pt-BR/nginx.js
module.exports = {
  nginx: {

    siteDeleted: "Site {domain} foi removido.",

  }

// Uso:
t('nginx.siteCreated', { domain: 'meusite.com' })
// → "Site meusite.com criado com sucesso!"
```

## 4. Persistência da Preferência

- Ao trocar idioma, salva em `data/settings/config.json` no campo `language`
- No carregamento inicial, `_app.tsx` lê a configuração via `GET /api/settings/config`
- Cookie `lang` também é setado para uso inicial antes da API responder
- O HTML `<html lang="...">` é atualizado dinamicamente

## 5. Traduções de Comandos e Mensagens do Sistema

Mensagens de erro do sistema (stdout/stderr de comandos shell) **não são traduzidas** — são exibidas como recebidas, mas com um prefixo no idioma correto:

```
{t('common.error')}: "nginx: [emerg] bind() to 0.0.0.0:80 failed"
```

Mensagens de sucesso da API incluem um código de mensagem, que o frontend traduz:

```json
{
  "success": true,
  "messageCode": "nginx.site_created",
  "messageParams": { "domain": "meusite.com" }
}
```
